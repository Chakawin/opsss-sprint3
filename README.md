# opsss-sprint3
ตอนนี้จะมีการ เริ่มต่อบอร์ด เขียนโค้ด ให้มีการอ่านเซ็นเซอร์ค่าพื้นฐานเพื่อแจ้งเตือนมายังจอ Oled display i2c เพื่อแจ้งเตือนผู้ใช้งาน
สิ่งที่ต้องแก้จะมี โค้ด ที่มีการเขียนผิดผลาดและ ปัญหาการหาตัวบอร์ดไม่เจอ แต่ณ ตอนนี้เจอเรียบร้อยพร้อม รัน แต่โค้ดไม่พร้อม งง
